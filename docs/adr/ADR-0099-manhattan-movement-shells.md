# ADR-0099: Манхэттенские оболочки возможных перемещений

**Статус:** принято  
**Дата:** 2026-09-27

## Контекст

Пользователь предоставил схему возможных перемещений: чёрный атом находится в исходной позиции, синим отмечена первая дистанция, оранжевым — вторая. Схема уточняет, как именно нужно трактовать «два шага по сетке» из ADR-0098.

## Решение

1. В 2D дистанция кандидата от текущего атома равна манхэттенской норме координатного смещения: `r = |Δx| + |Δy|`, где координаты выражены в шагах серой сетки. Межузельные позиции имеют полуцелые координаты и учитываются тем же правилом.
2. Первая оболочка (`r = 1`, синий цвет на схеме) содержит четыре соседних узловых позиции по осям и четыре диагональных межузельных положения.
3. Вторая оболочка (`r = 2`, оранжевый цвет) содержит узловые позиции по осям на два шага и по диагоналям на один шаг по каждой оси, а также соответствующие межузельные положения. Позиции с `r > 2` не рассматриваются.
4. В 3D сохраняется манхэттенское расстояние `r = |Δx| + |Δy| + |Δz|`. Диагональный переход между узлом и центром соседнего куба имеет расстояние `r = 1,5` и относится к **первой** оболочке. Осевые переходы между позициями одного вида с `r = 1` также относятся к первой оболочке; вторая оболочка имеет `r = 2`. Это правило классификации оболочки не изменяет числовое расстояние.
5. Принадлежность оболочке лишь делает позицию кандидатом. Она не отменяет ограничений вместимости, контактной связности, границы поля и экспертных весов типа позиции.

## Последствия

- Диагностика на паузе отображает первую и вторую оболочки разными цветами: синий для первой оболочки (в 3D также `r = 1,5` для узел↔межузлие), оранжевый для `r = 2`.
- Алгоритм и тесты перечисляют кандидаты по координатной формуле, а не обходом графа контактов.
- Это решение уточняет правило дистанции в ADR-0098 и заменяет в ADR-0097 только упоминание топологической дистанции как фактора выбора результата.
