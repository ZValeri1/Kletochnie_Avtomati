# ADR-0122: Вероятности направления движения внешнего атома

**Статус:** принято

**Дата:** 2026-10-08
**Уточняет:** ADR-0099 и правила переходов внешних атомов

## Контекст

Контактная связность запрещает отрыв атома от металла, но допускает длинные одноатомные цепочки. При одинаковой вероятности всех внешних направлений такие цепочки растут далеко от поверхности и не создают ожидаемый эффект компактного распухания металла.

## Решение

1. Для перехода атома `outside → outside` направление определяется изменением расстояния до ближайшего узла фиксированной границы металла. Используется существующее манхэттенское расстояние топологии.
2. Если расстояние уменьшается, направление называется `toward_metal`; если не меняется — `along_surface`; если увеличивается — `away_from_metal`.
3. Вероятности направлений по умолчанию равны соответственно `0.5`, `0.3` и `0.2`. Они доступны в конфигурации до старта симуляции и обязаны быть в диапазоне `0…1` и в сумме давать `1`.
4. Для внешней позиции применяется `P(outside) × P(direction)`. Вероятность направления делится поровну между доступными позициями с одинаковыми типом назначения, оболочкой и направлением.
5. Вероятность непосредственного входа во внутреннюю позицию продолжает определяться существующим параметром `external_metal`; направляющая тройка к нему не применяется.
6. Допустимые переходы, энергетический порог, оболочки и инвариант контактной связности не меняются.

## Последствия

- Внешние атомы чаще возвращаются к поверхности или перемещаются вдоль неё, чем продолжают цепочку наружу.
- Рост наружу остаётся возможным с вероятностью `0.2`, поэтому образование новых слоёв не запрещено жёстко.
- Если для одного направления нет допустимых назначений, соответствующая вероятностная масса приводит к отсутствию перехода, как и другая недостающая масса в текущей модели.
- Snapshot и API конфигурации содержат отдельный объект `external_direction_probabilities`; frontend позволяет редактировать все три значения.

## Проверки

- доменная диагностика возвращает `0.5 / 0.3 / 0.2` для известных назначений к поверхности, вдоль неё и наружу;
- API принимает изменённую нормированную тройку и отклоняет сумму, отличную от `1`;
- frontend показывает три редактируемых вероятности и их значения по умолчанию;
- существующие тесты переходов и production-сборка остаются зелёными.
