# ADR-0121: Серверный предварительный просмотр ручной операции

**Статус:** принято  
**Дата:** 2026-10-07  
**Закрывает:** UI-04 и предварительный просмотр редактора из `TZ_FRONTEND.md`  
**Уточняет:** ADR-0094, ADR-0119

## Контекст

Редактор должен показывать метрики до и после планируемого добавления, удаления, переноса атома или изменения 2D-границы. Frontend не может достоверно вычислить результат локально: допустимость операции и классификация дефектов принадлежат серверной модели, а серверный snapshot остаётся единственным источником истины.

## Решение

1. Добавить `POST /api/simulations/{simulation_id}/edit/preview` с тем же versioned payload, что и команда `/edit`.
2. Ответ `PreparationEditPreview` содержит текущую публичную revision, вид операции, `metrics_before/after` и `counts_before/after`.
3. Preview выполняет те же серверные проверки, что реальная операция, но не изменяет state, snapshot, revision, RNG, журнал или историю.
4. Результат preview считается устаревшим при смене simulation или revision и удаляется из интерфейса.
5. `DestinationOption` содержит `selectable` и `block_code`; заблокированные позиции не предлагаются как допустимый выбор, но остаются видимыми вместе с серверной причиной.
6. Фактическая команда `/edit` остаётся отдельным явным действием пользователя. Успешный preview не является резервированием позиции и не гарантирует успех после изменения revision.

## Последствия

- Frontend не дублирует физические правила и не делает optimistic physics mutation.
- Один и тот же backend определяет preview, причину отказа и фактический результат операции.
- Новый публичный DTO требует зеркального runtime decoder в TypeScript и общей contract fixture.
- Клиент обязан передавать `expected_revision`; устаревший preview отклоняется или игнорируется.

## Проверки

- preview возвращает серверные метрики и счётчики, оставляя состояние и revision неизменными;
- preview отклоняет недопустимую операцию тем же структурированным кодом;
- список назначений отделяет `selectable` от заблокированных вариантов;
- UI показывает ожидание preview, сравнение «до/после» и причины блокировки;
- после нового snapshot старый preview не отображается.
