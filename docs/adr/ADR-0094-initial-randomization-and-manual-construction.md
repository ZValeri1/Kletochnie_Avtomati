# ADR-0094: Случайная и ручная сборка начальной структуры

**Статус:** принято  
**Дата:** 2026-09-27

## Решение

1. В режиме «абсолютно случайная дефектная решётка» используется нормальное распределение. Оно заменяет прежнюю биномиальную схему. Конкретные параметры нормального распределения и распределение его параметров между категориями дефектов уточняются отдельно.
2. В 2D пользователь может задать область металла ортогональным замкнутым контуром. Пока допускаются только горизонтальные и вертикальные сегменты; поддержка произвольных замкнутых форм откладывается.
3. В 3D область металла остаётся прямоугольным параллелепипедом; ручное рисование объёмной границы не входит в текущую версию.
4. Вкладка «Редактирование» позволяет перемещать, добавлять и удалять атомы для ручной сборки атомной структуры. Все операции выполняются только на паузе, должны соблюдать вместимость позиций и связность с областью металла и сразу обновляют счётчики дефектов и числа атомов.

## Приоритет и последствия

- Требование ADR-0093 о неизменности числа атомов при ручном редактировании отменяется; это ограничение остаётся для обычных событий облучения.
- Редактор показывает до и после каждой операции `N_atoms`, `N_V`, `N_I` и `N_As`, а также понятную причину отказа при попытке создать изолированный атом или разорвать связанную структуру.
- Нормальная случайная генерация сохраняет `seed_init` и после отбора недопустимых размещений обязана оставаться воспроизводимой.
