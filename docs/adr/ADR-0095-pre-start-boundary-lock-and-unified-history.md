# ADR-0095: Блокировка границы после запуска и единая история

**Статус:** принято  
**Дата:** 2026-09-27

## Решение

1. В режиме случайной начальной конфигурации количества `N_V`, `N_I` и `N_As` разыгрываются независимыми усечёнными нормальными распределениями с отдельными параметрами `μ` и `σ`.
2. Ортогональная граница 2D-области металла редактируется только на этапе подготовки до первого акта облучения. После запуска симуляции она навсегда фиксируется для этой траектории.
3. После запуска атомы продолжают изменять положения через события облучения; блокировка относится к геометрии области металла, а не к атомной динамике.
4. История `undo/redo` едина для подготовки структуры, ручного редактирования и актов облучения. Каждый checkpoint хранит физическое состояние, геометрию на этапе подготовки и состояние RNG. Новый шаг после `undo` удаляет redo-ветку.

## Последствия

- Перед первым актом пользователь может подготовить форму и состав структуры; затем получает неизменяемую топологию и воспроизводимую траекторию.
- Интерфейс отображает состояние `Подготовка` до первого акта и `Симуляция` после него; редактирование границы доступно только в первом состоянии.
- Конкретные стартовые значения `μ` и `σ` остаются параметрами конфигурации, а не зашитыми константами.
